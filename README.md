把任务 JSON 放进 `tasks/` 目录，并在仓库简介（Description）中保留上面的仓库标记，WorkDaddy 即可自动收录本仓库的公开任务。

## 任务列表

- [逐账号例行发送（Hy3，剔除今日已完成登录任务的账号）](tasks/keep-accounts-active-hy3-skip-checked-in.json)

## 任务说明

**逐账号例行发送（Hy3，剔除今日已完成登录任务的账号）**

两阶段执行：先筛选、再发送。

1. **筛选（不切换账号）**：遍历全部账号，逐个查询今日登录任务（签到）状态。
   - 已完成 → 标记剔除，不参与后续发送；
   - 未完成 → 列入发送名单；
   - 查询失败 → 按未完成处理，避免漏发。
2. **发送（真实切换账号）**：名单为空时直接提示"所有账号今日均已完成"并结束，全程零切换；名单非空时对名单内账号依次切换，使用 `hy3` 新建会话发送 `1+1=`，按会话回执等待回复完成；循环结束时自动恢复开始时的账号。部分完成时，已完成的账号仍会被快速切换但跳过发送（引擎限制：`account.forEach` 无法接收动态账号列表）。

行为要点：

- 用账号级 `state` 在阶段之间传递筛选结论（按任务 ID + 账号 UID 隔离，24 小时自动过期）。
- 触发方式为手动，不会自动运行；并发策略 `skip`，运行中不重入。
- 只读 `account.status` 判断账号是否需要发送，不额外请求网络。

## 安装

WorkDaddy → 自动化 → 公开任务 → 找到本任务 → 导入。

## 免责声明

任务会操作本机已登录的账号，导入前请确认其行为符合你的预期。
